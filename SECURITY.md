# Security Policy

## Supported versions

The latest version published on npm receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report them privately via
[GitHub Security Advisories](https://github.com/magrinj/expo-screen-time/security/advisories/new)
or by email to **contact@magrin.fr**. You can expect an initial response within a
few days.
