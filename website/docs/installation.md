# Installation

```bash
npm install expo-screen-time
# or
yarn add expo-screen-time
# or
bun add expo-screen-time
```

Then add the config plugin and run a prebuild — see [Configuration](./configuration.md).

:::tip
`expo-screen-time` is a native module with iOS extension targets. It cannot run in Expo Go; you need a [development build](https://docs.expo.dev/develop/development-builds/introduction/).
:::
