# Importing

```typescript
import ExpoScreenTime, {
  useScreenTimePermissions,
  ExpoScreenTimeActivityPicker,
  DeviceActivityReport,
  ApplicationLabel,
  CategoryLabel,
  WebDomainLabel,
} from 'expo-screen-time';
```

The default export (`ExpoScreenTime`) holds all the imperative functions documented in this section. Components and the permissions hook are named exports — see [Components](../components.md).
