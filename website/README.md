# expo-screen-time docs

[Docusaurus](https://docusaurus.io/) site for **expo-screen-time**. Published to
GitHub Pages at https://magrinj.github.io/expo-screen-time/ by `.github/workflows/docs.yml`.

```bash
cd website
bun install
bun start          # local dev server with hot reload
bun run build      # production build into website/build
bun run serve      # serve the production build locally
```

Docs content lives in `docs/`. The sidebar is autogenerated from the folder
structure — ordering comes from each page's `sidebar_position` frontmatter and
the `_category_.json` files. Drop a new `.md` in `docs/` and it shows up.
